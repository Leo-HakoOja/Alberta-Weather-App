# Design Tokens (Alberta Direction)

## Color Tokens

### Primary
- `color.primary.900 = #0B3A82` (Alberta Blue)
- `color.primary.700 = #2F6FB2` (Prairie Sky)
- `color.accent.500 = #F2C94C` (Alberta Gold)

### Surface
- `color.surface.base = #F5F8FF`
- `color.surface.soft = #FFF9EC`
- `color.surface.card = #FFFFFF`

### Text
- `color.text.primary = #121212`
- `color.text.secondary = #4C5353`
- `color.text.onDark = #FFFFFF`
- `color.text.onDarkMuted = rgba(255,255,255,0.70)`

### State
- `color.state.success = #2E7D32`
- `color.state.warning = #B26A00`
- `color.state.danger = #B00020`

## Typography Tokens
- Hero temperature: `displaySmall` + 700
- Section title: `titleLarge` + 700
- Card value: `titleMedium` + 700
- Labels/meta: `labelMedium` / `bodySmall`

## Component Notes
- Hero card uses Alberta Blue -> Prairie Sky gradient
- Highlight chips can use Gold accents sparingly
- Keep precipitation/alert colors semantic (not decorative)
- Maintain strong contrast in dark mode
